# 高爾夫・身心健康與人際互動

從高爾夫談身心健康與人際互動，並整理入門、品格培養、心理訓練、禮儀、規則與差點、裝備、體能與防護、2026 年賽事、各國球場數量與台灣南部球場草種的靜態網站。

網站：https://kuanyuhou.github.io/golf-wellbeing-connection/

## 修改方式

- 各頁內文在 `content/*.html`，共用的頁首、導覽列、分享標籤和頁尾在 `build.mjs`。
- 分享預覽圖的原始設計在 `og/og.html`，輸出為 `og-image.png`（1200×630）。
- 修改後執行 `node build.mjs` 重新產生根目錄的頁面，再提交推送。
